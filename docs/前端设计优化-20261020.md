# 前端设计优化与静态发布

2026-10-20，按用户最新未序娘立绘和控制中心参考图优化，完成线上静态发布。未修改后端、Agent 或操作权限配置。

## 页面改动

- 保留完整首页；确认原大立绘与用户新附件 SHA-256 一致，继续使用原稿，更新三视图素材，调整首页立绘排版和头像显示窗口，没有重绘角色。
- 概览改为指标栏、实例列表、右侧详情、未序娘卡片、节点状态卡。去掉“告警源尚未接入”等过时占位面板，监控入口指向已有监控页。
- 新增实例名称/节点搜索、节点过滤、观测状态过滤和清空筛选；选中实例用中央 ID 绑定，详情提供实际来源、指标、采集时间、展开标识、日志与最近任务入口。
- 访问模式依据当前身份能力及只读开关显示；查看令牌不能因为生产已开放操作就显示为“可操作”。
- 实例表复用既有控制函数，原确认弹窗、幂等、任务链路和 UNKNOWN 恢复逻辑保留。长列表在面板内滚动，移动端表格横向滚动限定在面板内。
- 修复手机首页导航、能力区和路线图溢出，保留未知/过期/MOCK 标记；未将参考图里的示例数据写死。

## 代码位置与验证

`frontend/src/components/OverviewPanel.vue` 管理概览筛选、选择和详情；`InstanceTable.vue` 新增紧凑显示与详情选择事件，普通实例页仍沿用原展示；`App.vue` 负责连接既有业务入口；`brand-theme.css` 保存视觉和响应式规则。

前端 60 项行为测试通过，TypeScript 检查和生产构建通过。新增组件后首次回归有 7 项测试因编译组件的测试模块替身未注册 OverviewPanel 而失败，补齐替身后原断言全部通过，未删除失败断言。

1440px/390px 浏览器验证共 18 项通过，包括真实实例、搜索、详情、空结果、日志入口、操作确认后取消、无页面溢出和无脚本异常；查看身份及节点/状态组合筛选另有 4 项通过。本次没有发送任何生产操作写请求。

## 发布与恢复

`deploy/frontend/publish-static.py` 校验静态包摘要、拒绝危险归档路径，备份原站点；先复制资源，最后原子替换 index，保留旧哈希资源供已打开页面访问。80/9090 的正确 Host 入口均核对新 index 摘要。随后从公网再次完成浏览器验证，截图仅在本机私有目录保存。

此脚本只更新静态站点；原前四阶段审计的静态摘要对应当时版本，本轮新摘要以本报告链接的发布结果为准。若需回退，使用服务器本次 frontend release 目录的 previous-static.tar.gz；先核验备份，再恢复对应 index 与资源，避免改动后端服务。
