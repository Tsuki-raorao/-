# 域名 HTTPS 与备案上线

2026-10-20，北京时间。备案通过后，将已有 Argus 站点的主域名与 www 域名正式接入 HTTPS，保留 IP 80/9090 预览和已有操作身份。真实域名/IP 及令牌不在本报告重复记录；正式入口与操作令牌说明在本机忽略目录。

## 发布内容与实际边界

- 两个域名的 A 记录已指向控制机；未发现 AAAA，不额外修改 DNS 或 Minecraft 的子域名/SRV。
- 复用服务器已有 Certbot 5.8.0，独立申请 `argus-domain` 证书，两个 DNS 名都在 SAN 中。当前有效期到 2027-01-18；证书私钥仅留服务器受保护目录，未下载到仓库。
- Argus 的域名 HTTP（80/9090）返回 308 到对应 HTTPS 域名，路径和查询字符串保留。ACME 挑战仍直接提供文件；IP 80/9090 继续原入口。
- 独立的 `zz-argus-domain-https` 配置按 SNI/Host 区分域名。特别放在 relay 配置之后加载，避免抢占原来无默认标记的 IP:443 站点；已有聊天服务的 IP TLS 叶证书摘要保持，其他站点配置摘要不变。
- TLS 使用 1.2/1.3，独立会话缓存；不批量覆盖 Nginx 全局配置，也不修改同机其他项目。
- 新增 Argus 专属自动续期 timer，每天 UTC 02:15/14:15 检查（北京时间 10:15/22:15），允许随机延后最多一小时。保留聊天服务自己的续期 timer，不合并所有证书的运维责任。
- 首页和控制台页脚统一展示用户提供的 **闽ICP备2026040659号**，链接 `https://beian.miit.gov.cn/`，新窗口带 `noopener noreferrer`。

备案通过和 TLS 证书签发是两件事：前者是网站备案状态，后者验证浏览器访问的主机名并加密连接。本轮没有将完整账号体系或 AI 集成称为完成。

## 具体写了什么，怎么做

| 文件 | 本轮实现与理由 |
|---|---|
| `deploy/nginx/deploy-domain-https.py` | 从现有 Argus 站点保留 root、API 代理、静态缓存和隐藏路径限制；拆分 IP 预览和域名重定向、添加独立 TLS 站点；备份、nginx -t、reload、验证及失败恢复。检查既有 IP TLS 证书与其他配置，避免同机路由冲突 |
| `deploy/nginx/publish-domain-footer.py` | 校验上传归档与明确的上一前端发布摘要；白名单只接收 index 和 JS/CSS；资产先发布、index 最后原子替换，旧哈希资源保留。备份旧 index 和发布记录，再更新当前静态摘要 |
| `frontend/src/components/IcpRecord.vue` | 首页和控制台复用同一备案链接，避免两个页面分别维护号码；包含键盘 focus 样式 |
| `frontend/src/App.vue` / `styles.css` | 在两种布局放入备案组件；页脚可换行以适应手机 |
| `frontend/tests/refresh.test.mjs` | 为新增展示组件补充现有 setup 测试的模块替身；没有删改业务断言 |
| `scripts/acceptance/domain-https-check.cjs` | 公网 Edge 验证两个域名×1440/390 两种宽度；检查 HTTPS、页脚、真实目录、操作能力、确认框和监控；确认框取消，不对业务容器执行动作 |

证书采用 webroot 验证，借助已运行 Nginx 提供挑战文件，不停站签发；续期成功后的 deploy hook 先 `nginx -t` 再 reload。流程依据 [Certbot 官方文档](https://eff-certbot.readthedocs.io/en/stable/using.html#webroot)，部署后又实际执行 `renew --cert-name argus-domain --dry-run --run-deploy-hooks`，成功而非只安装 timer。

## 使用、恢复与后续维护

优先使用正式 HTTPS 域名。HTTPS 与旧 IP 页面属于不同 origin，sessionStorage 不共享，首次进入控制台需重新输入原操作令牌，不能把按钮禁用直接解释为服务端又关闭了操作。查看令牌权限仍为只读。

Nginx 修改前的配置及默认 TLS 摘要在服务器 `/opt/argus/backups/domain-https-*`；页脚更新前 index 和发布状态在 `/opt/argus/backups/domain-footer-*`。回退站点前先核验备份，恢复原 Argus 站点并移除本次独立 HTTPS 配置，`nginx -t` 成功再 reload。静态回退恢复旧 index 并保留其旧资源，同时对齐当前静态发布摘要；不要还原数据库或修改其他项目的 TLS 配置。关闭本轮续期时只停 Argus 专属 timer，不停止 relay timer。

磁盘发布前约剩 942MB、发布后约 940MB（98% 使用率）；本轮没有拉镜像或安装额外 ACME 环境，也没有删除其他项目文件。后续需制定备份与旧静态版本保留策略，防止空间耗尽。Certbot 当前复用同机既有虚拟环境，维护该环境时需兼顾两个独立续期任务。
