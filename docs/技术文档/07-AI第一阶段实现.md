# AI 第一阶段接入说明

当前已落地第一条只读模型调用链：`GET /api/ai/diagnose?question=...`。源码已编译并部署到控制中心；V9 迁移已创建 `ai_diagnoses` 诊断记录表，线上已实际调用 DeepSeek-V4-Flash 返回回答和证据引用。

默认关闭。启用时通过 IDEA 环境变量或服务器私有 EnvironmentFile 注入：

```text
ARGUS_AI_ENABLED=true
SILICONFLOW_BASE_URL=https://api.siliconflow.cn/v1
SILICONFLOW_MODEL=deepseek-ai/DeepSeek-V4-Flash
SILICONFLOW_API_KEY=<只放在本地运行配置>
```

这一版只允许生成只读分析回答，已把节点、实例、日志数量和任务数量作为授权快照上下文；仍不允许执行任务。下一步会补充真实日志与任务事件明细、结构化“结论/依据/未知项/建议”、RAG 检索和前端对话页面。

密钥不得进入仓库、日志、测试快照或前端；生产启用前应使用新生成的密钥。
