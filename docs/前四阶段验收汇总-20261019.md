## 数字应当怎样使用

- 云端隔离读取：20 闭环并发、300 秒、138840 次查询，462.743 次/s，P95 88.367ms，P99 141.177ms，0 错误；不是生产用户流量或系统峰值。
- 合成 HTTP Agent、真实采集代码/MySQL：100 节点一轮从 57.398s 到 14.801s，最旧采样年龄从 57.138s 到 14.537s，并发峰值 4；不是 100 台真实服务器。
- Redis 暂停/停机：8 条正式任务均完成，40 条事件/Outbox 完整；故障时接收约 529–537ms；恢复有客户端重连等待，漏写副本不会自动补回。
- 本轮完整后端回归 105 项：93 通过、12 个外部环境专项按条件跳过，0 失败；后续监控补充定向 6 项全部通过，其中包含真实 MySQL。外部 Broker/MySQL/浏览器证据分别记录，不重复累加为一个虚构总数。
- Agent 内存修正后 92 个 Java 场景与 3 组独立 JSON 契约检查通过；前端 60 项测试和构建通过。
- 生产最终审计 20 项、浏览器 19 项通过；七类监控规则有评估记录，两个真实 HOST 节点采集正常，队列 ready=0/dead=0、消费者连接正常。

## 保留的边界

生产保持只读及 Agent 控制关闭。业务动作在独立容器验收；真实游戏容器的 ID、StartedAt 和运行基线保持。本轮不宣称跨节点容灾、注册登录全面完成、Redis 读取加速、短信邮件通知或 AI 验收。

线上历史目录仍有一条已标识 MOCK 节点；它没有被当成数据库主机或第三台真实 Agent。Linux 内存历史的口径变更已记录，恢复告警不等于释放内存。生产回退的应用兼容性在隔离副本验证，生产未执行数据库覆盖恢复。
