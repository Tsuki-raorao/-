# Argus 心跳压测报告

测试日期：2026-10-10（Asia/Shanghai）

## 测试范围

本轮测试针对本机隔离启动的 Argus Agent Mock 服务，接口为 `POST /api/agent/heartbeat`。服务监听 `127.0.0.1:18090`，不会访问生产服务器、MySQL、Redis、Minecraft 或 Docker。

请求体固定为：

```json
{"nodeId":"node-local","status":"ONLINE"}
```

## 面试时的准确表述

本轮是在隔离 Mock Agent 上完成的接口基准压测，不把它当成生产容量结论。测试使用 64 并发发送 2,000 次心跳，成功率 100%，吞吐约 4,870 req/s，P95 12 ms、P99 173 ms。下一步如果要给出生产容量，需要在隔离环境接入真实控制中心、MySQL 和 Redis，逐步增加 Agent 数量，并记录数据库连接池、慢 SQL、CPU、内存和网络指标。

## 限制

- 本轮没有压测真实生产 Agent，避免影响 Minecraft 和现网数据库。
- Mock 接口只验证 HTTP 接收和响应，不包含真实快照落库、节点锁和网络抖动成本。
- P99 明显高于 P95，说明存在少量调度或连接尾延迟；正式报告需要重复多轮并观察长尾分布。
- 仓库当前 Agent 的心跳接口是被动响应接口，控制中心主要通过只读网关拉取健康和实例快照；因此本报告应称为“心跳接口基准压测”，不能表述成完整主动心跳链路压测。
