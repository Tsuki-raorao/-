# 公开仓库与本地配置

本仓库发布可继续开发的源码、测试、通用部署模板和实际进度。服务器清单、运行时凭据、个人目录、生产数据和未脱敏的运维记录不属于公开材料。

## 配置约定

- 数据库连接通过环境变量占位符注入；`MYSQL_HOST`、`MYSQL_DATABASE`、`MYSQL_USER`、`MYSQL_PASSWORD` 必填，`MYSQL_PORT` 默认 `3306`，不提供默认远程连接或账号。
- 本地与 Git 使用同一份源码，不另存包含真实连接的代码版本。用户在个人 IDEA 运行配置中填写环境变量，不勾选 `Store as project file`；步骤见 [数据库接入](数据库接入.md)。
- API 和 Agent 令牌通过对应环境变量提供。仓库内生产模板的密码和令牌为空，本地 Agent 配置使用 mock。
- `example.com` 子域名以及 `192.0.2.0/24`、`198.51.100.0/24`、`203.0.113.0/24` 属于示例值，不表示任何已部署的服务。
- 部署脚本中的主机角色、容器名和目录需要按使用者自己的环境配置；不要把替换后的真实环境文件提交回来。

## 版本管理范围

根目录只允许源码、文档、模板和脚本进入常规 Git 跟踪。`.gitignore` 排除本地私有目录、IDE 配置、交接包、备份、日志、数据库文件、密钥、压缩包、依赖缓存和编译产物。发布前仍应审查 `git diff --cached`；忽略规则不会自动移除已经提交的内容。

日常自动化测试使用隔离 H2 与本机 mock 服务，无需真实凭据。真实 MySQL 验证应使用独立测试库，不能把本地测试通过写成生产连接验证通过。

当前公开进度见 [开发进度](开发进度.md)，接手说明见 [交接文档](交接文档.md)。源码中的测试令牌只用于本地测试，不能作为生产凭据使用。
