## 保持的保护

- 生产配置保持 API 只读与中央/Agent 控制关闭；真实采集和远程操作是不同开关。
- UNKNOWN 默认保留互斥；本轮核对只在独立授权及完整证据验证后条件释放原锁，原 UNKNOWN 永不改写。确认 Agent 已接收后记录丢失不能按 404 重放，旧 Inbox 不能直接覆盖后上线。
- Agent 网关默认关闭，启用后要求令牌与目标主机白名单；不转发任意 URL 或 shell。
- HTTP 请求体、线程、队列及命令输出有界，命令使用参数数组，不执行 shell 拼接。
- 前端开发/生产均显示真实 API 错误；模拟数据明确标注，不计入真实近期统计。
- MySQL profile 默认不初始化演示数据，真实连接只由私有运行配置注入。
