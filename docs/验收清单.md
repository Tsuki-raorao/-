## 复验命令

在仓库根目录执行，准备 JDK 17、Maven 3.9+、Node.js 与已有前端依赖：

```powershell
mvn -f backend/pom.xml test
.\scripts\test-agent.ps1
npm --prefix frontend test
npm --prefix frontend run build
```

第一次安装前端依赖可执行 `npm --prefix frontend ci`；本轮复用已安装依赖。Agent 测试脚本同时编译源码并用独立 JSON 解析器校验输出，产物保存在忽略提交的 `agent/out-test/`。

后端 MySQL 专项仅在显式设置 `ARGUS_TEST_MYSQL_URL`、`ARGUS_TEST_MYSQL_USER`、`ARGUS_TEST_MYSQL_PASSWORD` 时执行，必须使用符合测试约束的本机一次性空库，不可复用应用生产变量。无这些配置时该测试跳过，属于 H2/mock 检查，不等于全部测试均实际执行。详情见 [数据库接入](数据库接入.md)。

## 功能复验要点

| 检查 | 预期 |
|---|---|
| API 认证与只读 | 无效令牌拒绝，健康接口可探活；只读写请求拒绝，网页按钮禁用 |
| 双节点同名实例 | 中央 ID 不同，按所属节点读取各自日志，旧任务外键不变 |
| 零值与缺失 | 真正 0 保留，未知显示未采集/不可用，MOCK 与 LEGACY 明确标记 |
| 数据新鲜度 | 失败不推进完整成功时间；超过 180 秒标旧，完整批次未发现立即标旧 |
| 日志错误与竞态 | 空日志是成功，错误不是空成功；切换、离开或注销后旧结果不覆盖 |
| 大输出与队列 | 超限/超时有明确结果，进程清理；有界 HTTP 等待队列施加背压 |
