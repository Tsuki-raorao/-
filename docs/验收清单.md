# 未序 Argus 验收清单

本清单区分已存在的模块检查与尚未完成的产品闭环。执行前记录提交号、JDK/Maven/Node.js 版本；以下全部使用本地环境，不需要真实服务器凭据。

## 基础构建

在仓库根目录执行：

```powershell
mvn -f backend/pom.xml test
npm --prefix frontend ci
npm --prefix frontend run build
```

Agent 可独立编译：

```powershell
$agentSources = Get-ChildItem agent/src/main/java -Recurse -Filter '*.java' | ForEach-Object FullName
New-Item -ItemType Directory -Force agent/out | Out-Null
javac -encoding UTF-8 -d agent/out $agentSources
```

验收要求：后端测试通过；前端类型检查和构建通过；Agent 编译退出码为 0。2026-10-07 公开版脱敏后已重新完成上述检查：后端 8 项测试通过，前端与 Agent 编译通过。新修改仍需按影响范围重新验证；本次没有执行完整产品闭环验收。

## 本地 MVP 检查

| 检查项 | 操作与预期 |
|---|---|
| H2 启动 | 启动后端，`GET http://localhost:8080/api/health` 正常返回，并报告数据库可用 |
| 持久化 | 在隔离的测试数据目录验证重启后数据保留；不使用真实数据库做删除测试 |
| Agent mock | 用默认配置启动 Agent，健康与实例接口可读，不调用 Docker |
| Web 页面 | 开发服务器可访问概览、节点、实例、任务和日志页；核对未序 Logo 与头像 |
| 数据来源 | 关闭后端验证开发演示回退；再使用生产构建验证 API 错误不会变为演示成功 |
| API 认证 | 配置临时测试令牌后，缺失/错误令牌被拒绝，有效令牌按预期读取；健康检查仍可探活 |
| 只读保护 | 设置 `ARGUS_API_READ_ONLY=true`，确认写请求被拒绝，前端写按钮不可用 |
| 指标权限 | 给 mock Agent 注入临时令牌，未授权 `/metrics` 被拒绝，授权请求返回文本指标 |
| Agent 网关 | 仅在本地配置目标白名单和令牌后开启，检查节点与实例快照入库；不误认为 Agent 主动上报 |

## 尚不能判为完成的验收项

- [ ] 页面操作真实容器后，任务与容器最终状态一致，且失败、超时、重试均可追踪。
- [ ] Agent 和控制中心重启后，未完成任务可恢复且不会重复执行。
- [ ] 不同节点的同名实例不会相互覆盖。
- [ ] 网页日志来自所选节点和实例，断连与空日志可区分。
- [ ] 玩家数、TPS 与不可用指标由真实采集和状态标记支持。
- [ ] 多用户权限、细粒度授权、审计与凭据轮换完成。
- [ ] Redis、消息队列及高并发方案有实测数据与故障恢复证据。
- [ ] 历史指标、日志检索、告警与恢复通知形成链路。
- [ ] 数据库和业务实例在隔离环境完成恢复演练。
- [ ] AI/RAG 有检索来源、评估记录与执行权限边界。

## 公开交付检查

- [ ] 暂存区、历史提交和文档链接中无真实服务器地址、域名、账户、密钥或个人路径。
- [ ] 数据库文件、运行日志、备份包、交接归档和环境专用配置未被纳入版本控制。
- [ ] 配置示例可辨认为模板，必填秘密为空或由环境变量注入。
- [ ] 构建后的前端资源与静态图片未嵌入秘密或个人信息。
- [ ] 提交说明明确哪些已实现、哪些仍属于设计。

任何一项通过都应附带当前提交的验证证据；本清单中的未勾选项不表示已经执行。
