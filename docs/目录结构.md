# Argus 目录结构

这是源码仓库的快速导航。源码目录保持稳定，文档链接均以仓库根目录为基准。

## 可提交的源码与模板

| 目录 | 内容 |
| --- | --- |
| `backend/` | Java 17 / Spring Boot 控制中心、Flyway 迁移、MySQL/H2 持久化、任务队列、Redis 缓存和 RabbitMQ Outbox |
| `agent/` | 服务器 Agent、主机/Docker 采集、受保护接口、持久 Inbox 和任务执行边界 |
| `frontend/` | Vue + TypeScript + Vite 管理台、品牌图片和前端测试 |
| `deploy/` | Nginx、systemd、Docker Compose、数据库与 Minecraft 备份模板 |
| `scripts/` | 本地启动、测试、检查和项目状态备份脚本 |
| `docs/` | 项目说明、接口、设计、部署、验收、面试和技术资料 |
| `relay/` | 独立协作中转站；由另一会话维护，和 Argus 业务链路分开 |

## 本地私有目录

以下目录用于本机交接和验证，不属于源码交付，也不应提交到 Git：

- `handoff/`：交接压缩包、校验文件和交接包构建工作目录。
- `backups/`：项目状态快照和品牌验收备份。
- `local-private/`：真实环境记录、浏览器验收资料、令牌关联信息和测试日志。
- `backend/data/`、`frontend/dist/`、`backend/target/`、`agent/out/`：运行数据库、构建产物和编译输出。

这些目录已在根 `.gitignore` 中排除。清理前先确认是否仍需回滚或交接，不要把私有资料移动到源码目录。
