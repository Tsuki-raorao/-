# 未序 Argus 开发进度

更新日期：2026-10-07。本文描述仓库实现状态，不记录真实服务器运行情况。

## 当前阶段

基础只读 MVP 已完成，能够在本地以 H2 与 mock 配置运行，也具有 MySQL 和只读 Agent 对接能力。企业级架构目前处于设计阶段；非 AI 版本也尚未完成真实任务执行、实时日志与权限审计闭环。

## 已实现与限制

| 模块 | 已实现 | 当前边界 |
|---|---|---|
| Web 管理台 | 概览、节点、实例、任务、日志页面；自动刷新；API 令牌输入；只读提示；未序品牌资源 | 任务与日志页面的存在不代表对应远程链路已打通 |
| 控制中心 | REST API、参数校验、事务、统一响应、数据库健康检查 | 任务执行仅改变数据库中的实例与任务状态 |
| 数据库 | H2 默认配置、MySQL profile、Flyway V1–V3、节点/实例/任务/日志持久化 | 没有租户模型；实例 ID 尚未加入节点作用域 |
| Agent 采集 | 主机资源快照、Docker 容器发现、容器状态和 CPU/内存快照、日志查询 | 玩家数未采集；资源采集失败时部分字段可能返回 0 |
| Agent 指标 | 受 Bearer 令牌保护的 Prometheus 文本 `/metrics` | 仅提供接口，没有指标存储、历史图表或告警平台 |
| Agent 执行器 | mock 与 Docker 适配器、动作白名单、超时和队列上限 | 远程动作默认关闭；任务保存在内存，重启后不保留 |
| 只读网关 | 目标白名单、令牌、超时、读取 health/instances/logs 的接口 | 网页日志仍读取数据库；控制中心不下发执行任务 |
| 快照同步 | 开启后按固定延迟轮询 Agent 并写入节点与实例快照 | 默认轮次间隔 60 秒；不是主动注册/心跳或实时流 |
| 访问保护 | 可选 API Bearer 令牌、只读拦截、Agent 认证与网关启动校验 | 不是多用户登录、RBAC、细粒度授权或完整审计 |

## 尚未完成

1. 控制中心 → Agent → Docker → 执行结果回传的任务闭环，以及幂等、恢复、补偿机制。
2. 网页实时日志链路、采集时间与失效状态展示，以及真实 Minecraft 玩家数/TPS 适配器。
3. 跨节点实例唯一标识迁移，避免不同节点的同名容器相互覆盖。
4. 完整登录、角色权限、操作审计、凭据轮换和细粒度 Agent 权限。
5. Redis、消息队列、任务 Inbox/Outbox、多实例协调、高并发压测与容量结论。
6. Prometheus/Grafana/Loki 接入、历史指标、日志平台与告警闭环。
7. AI 对话、RAG、知识库检索与审批约束下的运维建议；“未序娘”目前仅是形象。
