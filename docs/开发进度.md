# 未序 Argus 开发进度

更新：2026-10-08，北京时间（UTC+08:00）。本文记录当前源码与验证范围，不以旧部署记录代替今日在线状态。

## 当前结论

基础只读 MVP 已具备。本轮服务器 Agent 重构已实现多节点实例身份、可信采集、网页 Agent 最近日志和资源边界保护，并通过模块与本机跨模块验证；**尚未部署，真实 Docker 执行、持久化任务、完整权限审计和 AI 仍未完成**。统一说明见 [项目说明与进度汇报](项目说明与进度汇报.md)。

## 本轮实现

| 模块 | 已实现 | 当前边界 |
|---|---|---|

| 数据库 | V1–V3 SQL + V4 Java 迁移；可空指标、来源/时间/同步结果；采集时间使用 `TIMESTAMP(6)` | MySQL DDL 隐式提交，不能承诺迁移失败整批回滚；生产尚未执行 |
| 采集协议 | Agent 1.1，区分 HOST/DOCKER/MOCK、真实 0 与 null、指标可用状态 | 玩家数/TPS 未采集，业务 Adapter 注册框架未实现 |
| 快照同步 | 完整清单先校验再事务保存；失败保留最近证据；区分尝试、健康与完整成功时间 | 默认关闭网关；启用后每轮完成等待 60 秒，单进程顺序拉取，不是主动心跳 |
| 网页 | 来源/缺失/过期标记；180 秒旧快照；完整新批次未发现的实例立即标旧 | 不是历史指标平台；未知和旧值不计入近期真实统计 |

| 执行与保护 | Bearer、目标白名单、只读开关、动作白名单及任务队列上限 | 控制中心只记录模拟任务；Agent 任务内存保存，真实动作默认关闭 |
| 品牌 | 银白“未序” Logo 与未序娘头像 | 仅展示，AI 对话/记忆/RAG 未实现 |
