## 2026-10-09 UNKNOWN 人工核对（本轮，未部署）

新增独立核对记录/队列/事件、Agent 不可变 CLOSED 回执及网页证据/确认流程。原 Task 的 UNKNOWN、原结果和原事件保持不变；Agent 原终态与本次观察是独立证据，不能回填实例采集。核对只允许 `ACKNOWLEDGE_UNCERTAINTY`，不重放原命令，不执行启动/停止/重启。

首次提交先读取原 Agent 记录、绑定与执行器证据，填写原因/人工证据并分别确认不重放及剩余风险。202 仅接收；BLOCKED 可按 GET 返回的原键/完整原文显式续办。只有有效回执持久化与原锁条件删除在同一事务完成后成为 APPLIED。以后新操作必须独立确认、新 UUID 和命令，旧回执不能删除新锁。开关、查看/操作令牌、允许名单和全局只读均由服务端验证。

### 可靠任务的实现范围

按 [冻结契约](可靠任务接口与恢复约定.md)，中央原来的数据库模拟成功已被持久队列替代，HTTP 202 只表示接收；Task、队列、实例互斥和追加事件在事务内保存。重复提交使用原幂等键，中央投递使用固定 commandId。Agent 原子文件保存 Inbox，PENDING 可恢复，RUNNING 崩溃转 UNKNOWN，不重放。任务结果不修改实例采集值，历史任务为 LEGACY_MOCK 且不生成投递。保证重复传输去重和保守的进程恢复，不承诺 Docker 副作用 exactly-once 或跨平台断电一致性。
