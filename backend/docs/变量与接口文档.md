# 变量与接口文档

## 1. 领域对象字段

| Java 字段 | 中文含义 | 数据库列 | 约束/说明 |
| --- | --- | --- | --- |
| `Node.id` | 节点 ID | `nodes.id` | 64 字符以内，主键 |
| `Node.name` | 节点名称 | `nodes.name` | 必填 |
| `Node.address` | 节点或 Agent 地址 | `nodes.address` | 必填；当前仅保存地址 |
| `Node.status` | 节点状态 | `nodes.status` | `ONLINE`、`OFFLINE`、`UNKNOWN` |
| `Node.lastHeartbeat` | 最近心跳时间 | `nodes.last_heartbeat` | 从未心跳时为空 |
| `Node.cpuPercent` | 主机 CPU 百分比 | `nodes.cpu_percent` | Agent 只读瞬时快照，范围 0–100 |
| `Node.memoryBytes` | 主机已用内存 | `nodes.memory_bytes` | 字节；采集失败为 0 |
| `Node.memoryTotalBytes` | 主机内存总量 | `nodes.memory_total_bytes` | 字节；为 0 时前端显示暂无指标 |
| `Instance.id` | 服务实例 ID | `instances.id` | 例如 `mc01`，主键 |
| `Instance.name` | 实例显示名 | `instances.name` | 例如“零壹” |
| `Instance.nodeId` | 所属节点 ID | `instances.node_id` | 外键到 `nodes.id` |
| `Instance.containerName` | 容器名称 | `instances.container_name` | 例如 `mc01` |
| `Instance.version` | 服务版本 | `instances.version` | 例如 `1.21.1-NeoForge` |
| `Instance.status` | 实例状态 | `instances.status` | `RUNNING`、`STOPPED`、`STARTING`、`STOPPING`、`UNKNOWN` |
| `Instance.updatedAt` | 状态更新时间 | `instances.updated_at` | 必填 |
| `Task.id` | 任务 ID | `tasks.id` | 主键；后续用于幂等键 |
| `Task.instanceId` | 目标实例 ID | `tasks.instance_id` | 外键到 `instances.id` |
| `Task.action` | 操作名称 | `tasks.action` | `START`、`STOP`、`RESTART` |
| `Task.status` | 任务状态 | `tasks.status` | `PENDING`、`RUNNING`、`SUCCEEDED`、`FAILED` |
| `Task.message` | 执行说明 | `tasks.message` | 最长 512 字符 |
| `Task.createdAt` | 创建时间 | `tasks.created_at` | 必填 |
| `Task.finishedAt` | 完成时间 | `tasks.finished_at` | 运行中为空 |
| `LogEntry.id` | 日志摘要 ID | `logs.id` | 主键 |
| `LogEntry.instanceId` | 所属实例 ID | `logs.instance_id` | 外键到 `instances.id` |
| `LogEntry.timestamp` | 日志时间 | `logs.log_timestamp` | 必填 |
| `LogEntry.level` | 日志级别 | `logs.level` | 例如 INFO、WARN、ERROR |
| `LogEntry.message` | 清洗后消息 | `logs.message` | 最长 4000 字符；原始大日志放 Loki |

## 2. 统一响应

所有接口返回：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

`code=0` 表示成功；校验错误为 HTTP 400；资源不存在为 HTTP 404。后续接入认证后，未登录和无权限分别使用 401/403，并保持响应结构稳定。

## 3. 接口清单

| 方法 | 路径 | 用途 | 请求/参数 |
| --- | --- | --- | --- |
| GET | `/api/health` | 检查控制中心进程 | 无 |
| GET | `/api/nodes` | 查询节点列表 | 无 |
| GET | `/api/nodes/{id}` | 查询节点 | 路径 `id` |
| POST | `/api/nodes` | 创建节点 | `{"name":"名称","address":"地址"}` |
| POST | `/api/nodes/{id}/heartbeat` | 更新节点心跳 | 可选 `{"status":"ONLINE"}` |
| DELETE | `/api/nodes/{id}` | 删除节点及其历史实例/任务/日志 | 生产只读模式下返回 405 |
| GET | `/api/instances` | 查询实例 | 无 |
| GET | `/api/instances/{id}` | 查询实例 | 路径 `id` |
| POST | `/api/instances/{id}/actions` | 创建并执行实例任务 | `{"action":"START"}` |
| GET | `/api/tasks` | 查询任务列表 | 无 |
| GET | `/api/tasks/{id}` | 查询任务 | 路径 `id` |
| GET | `/api/logs` | 查询日志摘要 | `instanceId` 可选，`limit` 默认 100、最大 500 |
| GET | `/api/agent-gateway/nodes/{nodeId}/health` | 读取 Agent 健康状态 | 网关默认关闭 |
| GET | `/api/agent-gateway/nodes/{nodeId}/instances` | 读取 Agent 实例快照 | 只读、需主机白名单 |
| GET | `/api/agent-gateway/nodes/{nodeId}/instances/{instanceId}/logs` | 读取 Agent 日志 | `limit` 默认 100、最大 1000 |

## 4. 配置变量

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `SPRING_PROFILES_ACTIVE` | 空 | 使用 `mysql` profile 连接 MySQL |
| `MYSQL_HOST` | 无，必填 | MySQL 地址；仅在个人运行配置或部署环境中设置 |
| `MYSQL_PORT` | `3306` | MySQL 端口 |
| `MYSQL_DATABASE` | 无，必填 | 数据库名 |
| `MYSQL_USER` | 无，必填 | 数据库账号 |
| `MYSQL_PASSWORD` | 无，必填 | 数据库密码，只允许运行时注入 |
| `ARGUS_DEMO_DATA_ENABLED` | `false`（mysql） | 是否插入演示数据 |
| `ARGUS_CORS_ORIGINS` | 本地 Vue 地址 | 允许跨域来源，逗号分隔 |
| `ARGUS_AGENT_GATEWAY_ENABLED` | `false` | 是否启用控制中心到 Agent 的读取网关 |
| `ARGUS_AGENT_GATEWAY_READ_ONLY` | `true` | 是否强制只读；当前必须保持 true |
| `ARGUS_AGENT_GATEWAY_REQUIRE_ALLOWLIST` | `true` | 是否强制校验 Agent 主机白名单 |
| `ARGUS_AGENT_GATEWAY_ALLOWED_HOSTS` | 空 | Agent 主机白名单，逗号分隔；开启网关前必须设置 |
| `ARGUS_AGENT_AUTH_TOKEN` | 空 | Agent Bearer 令牌，只允许运行时注入 |
| `ARGUS_AGENT_GATEWAY_CONNECT_TIMEOUT` | `3s` | 连接超时 |
| `ARGUS_AGENT_GATEWAY_READ_TIMEOUT` | `5s` | 读取超时 |
| `ARGUS_AGENT_SYNC_INITIAL_DELAY_MS` | `5000` | 首次 Agent 快照同步延迟（毫秒） |
| `ARGUS_AGENT_SYNC_INTERVAL_MS` | `60000` | Agent 快照同步间隔（毫秒） |
| `ARGUS_API_READ_ONLY` | `false` | 生产只读保护；开启后 API 写请求返回 405 |
| `ARGUS_API_AUTH_REQUIRED` | `false` | 是否要求控制中心 API 使用 Bearer 令牌；健康检查仍可探活 |
| `ARGUS_API_ACCESS_TOKEN` | 空 | 控制中心 API 访问令牌；只允许运行时注入，启用鉴权时不能为空 |
