## 2. 统一响应

所有接口返回：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

`code=0` 表示请求成功；创建/找回任务均为 HTTP 202，只表示接收，不代表动作完成。校验错误 HTTP 400；资源不存在 404；缺失或错误令牌 401；查看令牌写入、未授权目标、控制关闭为 403；全局只读下操作令牌写入为 405；幂等内容冲突、同实例未决任务、目标模式变化、删除有任务历史节点为 409。Agent 读取失败或响应无效为 502，网关未启用为 503。

## 3. 接口清单

| 方法 | 路径 | 用途 | 请求/参数 |
| --- | --- | --- | --- |
| GET | `/api/health` | 检查控制中心进程 | 无 |
| GET | `/api/nodes` | 查询节点列表 | 无 |
| GET | `/api/nodes/{id}` | 查询节点 | 路径 `id` |
| POST | `/api/nodes` | 创建节点 | `{"name":"名称","address":"地址"}` |
| POST | `/api/nodes/{id}/heartbeat` | 更新节点心跳 | 可选 `{"status":"ONLINE"}` |
| DELETE | `/api/nodes/{id}` | 无任务历史时删除节点、实例和日志 | 有任意任务历史返回 409；不会删除任务审计 |
| GET | `/api/instances` | 查询实例 | 无 |
| GET | `/api/instances/{id}` | 查询实例 | 路径 `id` |
| GET | `/api/instances/{id}/logs` | 中央 ID 定位远端最近日志，非流式 | `limit` 默认 100、限制 1–1000 |
| GET | `/api/control/capabilities` | 当前令牌可控制的动作/目标/模式 | 无 |
| POST | `/api/instances/{id}/actions` | 持久接收任务，异步执行 | `Idempotency-Key: <规范 UUID>`；`{"action":"START","expectedExecutionMode":"MOCK"}` |
| GET | `/api/tasks` | 查询最近任务 | 最近 100 条，完整分页后续实现 |
| GET | `/api/tasks/{id}` | 查询任务 | 路径 `id` |
| GET | `/api/tasks/{id}/events` | 追加事件时间线 | 按 sequence 升序 |
| GET | `/api/logs` | 查询日志摘要 | `instanceId` 可选，`limit` 默认 100、最大 500 |
| GET | `/api/agent-gateway/nodes/{nodeId}/health` | 读取 Agent 健康状态 | 网关默认关闭 |
| GET | `/api/agent-gateway/nodes/{nodeId}/instances` | 读取 Agent 实例快照 | 只读、需主机白名单 |
| GET | `/api/agent-gateway/nodes/{nodeId}/instances/{instanceId}/logs` | 读取 Agent 日志 | `limit` 默认 100、最大 1000 |

新增中央日志接口的 `data` 为 `{instanceId, nodeId, agentInstanceId, collectedAt, lines}`，其中 `instanceId` 是中央 ID，`collectedAt` 是控制中心成功读取时间，`lines` 是字符串数组。空数组仅表示 Agent 成功返回空日志；失败保持错误响应。原网关日志路径的 `instanceId` 仍指 Agent 局部 ID，原 `/api/logs` 仍查询数据库摘要。

同步错误码仅使用 `INVALID_HEALTH`、`HEALTH_REQUEST_FAILED`、`INVALID_INSTANCES`、`INSTANCES_REQUEST_FAILED`、`PERSISTENCE_FAILED`。节点健康成功而清单失败为 PARTIAL；完整空数组可为 OK，但历史实例保留旧 `lastSeenAt`。当 `lastSeenAt < node.lastSuccessfulSyncAt` 时，该实例未出现在最近完整清单中，应显示旧快照。未完成同步、失败、LEGACY/UNKNOWN 和超时数据也不能显示为新鲜实测。

capabilities 的 data 为 `{controlEnabled,canControl,allowedActions,targets:[{instanceId,executionMode,allowedActions}],reason}`。目标模式来自已知实例快照，UNKNOWN/LEGACY 不提供操作；提交时仍读取 Agent health 强校验。查看令牌 canControl 为 false，每个目标动作为空；操作令牌也只有命中中央允许列表和模式开关才提供动作。

事件为 `{id,taskId,sequence,fromStatus,toStatus,actor,reason,occurredAt}`，id 是 UUID 字符串，sequence 从 1 开始，首事件 fromStatus 为 null，actor 是 operator 或 worker，时间为 ISO Instant。UNKNOWN 停止自动重放且保留互斥；接口没有“自动重试 UNKNOWN”或解除锁功能。

浏览器同一次操作的 Idempotency-Key 保持不变；同键不同实例/动作/模式 409，相同内容返回原 Task。请求超时不能换键重做。同键找回不新建投递，即使任务控制开关已关闭仍可返回（需操作令牌、全局非只读）。commandId、内部目标地址、Agent 节点身份、storeId、执行模式和 expiresAt 在首次接受时固定。

中央向 Agent 的 POST `/api/agent/tasks` 只发送七个字符串：commandId、instanceId（远端局部 ID）、action（小写）、expectedNodeId（Agent 自报身份）、expectedStoreId、expectedExecutionMode、expiresAt。任务 GET/POST 使用独立控制令牌，health 使用读取令牌。接口详情见根目录 [可靠任务契约](../../docs/可靠任务接口与恢复约定.md)。
