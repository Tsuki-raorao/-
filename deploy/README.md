# Argus 部署模板

本目录只保存部署模板和说明，不会自动连接或修改云服务器。复制到服务器前先检查路径、用户、端口和备份状态。

## 目录

- `nginx/argus.conf.example`：域名反向代理模板。
- Agent 生产配置从项目根目录的 `agent/config/agent.properties.example` 复制，并通过环境变量注入令牌。
- `systemd/`：控制中心和 Agent 的 systemd 服务、环境变量模板，不包含真实密码。
- `mc01/backup-minecraft.sh`：Minecraft 变更前的只读容器/世界备份模板。
- `database/backup-argus-mysql.sh`：MySQL 逻辑备份模板，密码只从运行时环境读取。

## 推荐链路

```text
浏览器 -> Nginx 80/443 -> 前端静态文件
                         -> /api/ -> Argus 控制中心 127.0.0.1:9091（生产）
控制中心 -> Agent 8090（安全组白名单）
控制中心 -> MySQL 3306（安全组白名单）
```

此模板将控制中心绑定到网站节点的 `127.0.0.1:9091`，由 Nginx 转发 `/api`，不直接暴露 8080、8090 或 3306。端口和节点分布仅为部署示例，应按实际环境填写。生产 HTTPS 证书由服务器证书管理工具配置，真实证书路径不要写入仓库。

## 发布前检查

1. 确认 DNS 已指向最终网站服务器。
2. 确认前端 `dist/` 与后端 JAR 为同一版本。
3. 确认数据库备份和 Flyway 版本。
4. 确认 Agent 保持 mock/只读，完成连通性检查后再开放真实动作。
5. 确认 Minecraft 容器已完成独立备份，发布过程不重启它们。

详细恢复步骤见 [备份恢复操作手册](../docs/备份恢复操作手册.md)。
